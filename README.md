# dealership-agent

## Overview

An agentic AI customer service assistant for a used-car dealership. The
system is a modular monolith: a single FastAPI service that orchestrates a
LangGraph multi-agent workflow — one Supervisor delegating to a Sales Agent
(public, read-only listing and policy search) and an Account Agent
(customer-scoped order lookups and human escalation). Tools are exposed
through an MCP server so the agent layer stays framework-independent, and
identity/authorization are enforced server-side, never by the LLM.

See [CLAUDE.md](CLAUDE.md) for the full architecture decisions, the core
security invariant, and engineering standards this project is built to.

## Data Sources and Honesty Statement

This project is transparent about where its data comes from:

- **Car listings** are real market data sourced from a public dataset.
- **The transactional layer** (orders, customers, bookings) is **synthetic**,
  generated by a seeded, reproducible script under `data/scripts/`. No real
  customer or transaction data is used anywhere in this project.
- **Policy documents** (warranty, returns, financing policy, etc.) are
  hand-authored for this project, not sourced from any real dealership.

This distinction is never obscured in code, documentation, or output.
